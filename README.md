# Viral Life 2.0 — Telegram Mini App

Готовая сборка для Render: Telegram-бот, Mini App и игровой интерфейс. Сервер работает на чистом Node.js 18+ без сторонних зависимостей.

## Что реализовано

- плавное пошаговое обучение с затемнением и подсветкой активной кнопки;
- получение и ремонт стартового iPhone 5;
- выбор телефона перед съёмкой;
- камера и производительность каждого телефона в процентах;
- 3 ролика за 30 минут отдельно для каждого телефона;
- расчёт лайков, подписчиков, дохода и шанса вирусного ролика;
- установка уникального номера на конкретный телефон;
- бонус номера к охвату;
- максимум 3 телефона и 5 номеров;
- кейсы POCO, Xiaomi, Pixel, Samsung и iPhone с разными ценами;
- отдельная анимация кейса и появления выпавшего телефона;
- флагманские пулы: POCO — 2, Xiaomi — 3, Pixel — 3, Samsung — 4 Ultra, iPhone — 5 Pro Max;
- жидкое стекло, плавная навигация и Telegram haptic feedback;
- сохранение прогресса на устройстве игрока.

## Загрузка на Render

1. Распакуйте архив и загрузите **содержимое папки `viral-life-render-v2`** в GitHub-репозиторий.
2. В Render выберите **New → Web Service** и подключите репозиторий.
3. Настройки уже описаны в `render.yaml`. Если вводите вручную:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Health Check Path: `/health`
4. Добавьте Environment Variable:
   - `BOT_TOKEN` — токен Telegram-бота от BotFather.
5. Запустите Deploy.

После запуска сервер автоматически установит webhook, команду `/start` и кнопку меню «Играть». Адрес берётся из `RENDER_EXTERNAL_URL`. Для своего домена задайте `WEBAPP_URL`.

## Локальный запуск

```bash
npm start
```

Откройте `http://localhost:3000`. Без `BOT_TOKEN` игра работает как обычный сайт, но бот и webhook не подключаются.

## Важно перед публичным запуском

Сейчас прогресс хранится в `localStorage`, поэтому сборку можно сразу тестировать без базы. Для общего рынка, глобально уникальных номеров, защиты экономики и переноса прогресса между устройствами потребуется PostgreSQL и серверная авторизация Telegram initData.
